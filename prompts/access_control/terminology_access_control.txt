TERMINOLOGY (NL → ENUM)

Reader direction:
inlezer/in lezer/in lezers/in kaartlezer/in kaartlezers -> IN_ONLY
uitlezer/uit lezer/uit lezers/uit kaartlezer/uit kaartlezers -> OUT_ONLY
inuitlezer/inuit lezer/in- en uitlezer/in en uitlezer -> IN_OUT
geen lezer -> NONE
   Otherwise → null

Reader:
kaart/pas/badge → CARD
code/pincode/keypad → CODE
vingerafdruk → FINGERPRINT
gezicht → FACE_RECOGNITION
iris → IRIS_SCAN
bluetooth → BLUETOOTH
nfc → NFC
handzender → WIRELESS_KEYFOB
app → MOBILE_APP
kenteken → LICENSEPLATE_CAMERA

Lock:
motorslot → MOTORIZED_LOCK
magneet → MAGNETIC_LOCK
sluitplaat → ELECTRIC_STRIKE_PLATE
elektrisch slot → SOLENOID_LOCK
geen slot → NONE

Door closer:
deurdranger → MECHANICAL
elektrische deurdranger → ELECTRIC
zonder deurdranger → NONE

Exit:
exit knop → PUSH_BUTTON
elleboog → ELBOW_ACTUATED
uitrijlus → GROUND_LOOP
bewegingssensor → MOTION_SENSOR

Emergency:
noodknop → STANDALONE
gekoppeld aan inbraak → INTRUSION

Special case:
- uitrijlus -> exit_device = GROUND_LOOP
- never map "uitrijlus" to reader_direction
